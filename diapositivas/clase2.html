Lo tradicional

El bucle for

for clásicoconst frutas = ["manzana", "pera", "uva"];

for (let i = 0; i < frutas.length; i++) {
  console.log(i, frutas[i]);
}
// 0 "manzana" · 1 "pera" · 2 "uva"
  • inicio · condición · incremento
  • Permite break y continue
for...of (ES6)for (const fruta of frutas) {
  console.log(fruta);
}
// "manzana" · "pera" · "uva"
¿CUÁL USO?

for cuando necesitas el índice o cortar el ciclo; for...of cuando solo te interesa cada valor.

El for clásico es la base de todo: existe en casi todos los lenguajes. Explicar sus tres partes. Mostrar que i < length (no <=) porque los índices empiezan en 0. for...of es la versión moderna y más legible.
Métodos de array

forEach y map

forEach — solo recorreconst nums = [1, 2, 3];

nums.forEach((n, i) => {
  console.log(`${i}: ${n}`);
});
// 0: 1 · 1: 2 · 2: 3
// devuelve undefined
map — transformaconst dobles = nums.map(n => n * 2);
// [2, 4, 6]

const precios = [10, 20, 30];
const conIva = precios.map(p => p * 1.13);
// [11.3, 22.6, 33.9]

map siempre devuelve un array nuevo del mismo tamaño; el original no cambia.

Ambos reciben una función (callback) que se ejecuta por cada elemento, con (elemento, índice, array). Diferencia clave: forEach no devuelve nada, map devuelve un array nuevo. Error común: usar map sin usar su resultado, o forEach esperando un resultado.
Buscar y seleccionar

filter, find y findIndex

Los datosconst alumnos = [
  { nombre: "Ana",  nota: 85 },
  { nombre: "Luis", nota: 48 },
  { nombre: "Sara", nota: 92 },
];
Buscaralumnos.filter(a => a.nota >= 51);
// [{ Ana }, { Sara }]

alumnos.find(a => a.nota < 51);
// { nombre: "Luis", nota: 48 }

alumnos.findIndex(a => a.nombre === "Sara");
// 2   (-1 si no existe)
filter → array nuevo (0 a n elementos) find → el primero o undefined findIndex → su índice o -1
La función que reciben debe devolver true o false (una condición). filter se queda con todos los que cumplen; find se detiene en el primero. Preguntar: ¿qué devuelve filter si nadie cumple? → un array vacío [].
Acumular

reduce: de muchos a uno

Total de un carritoconst carrito = [15, 30, 5];

const total = carrito.reduce(
  (acc, precio) => acc + precio,
  0  // valor inicial de acc
);
// 50

Lo que devuelve cada vuelta se convierte en el acc de la siguiente. También sirve para contar, agrupar o construir objetos.

El método que más cuesta al principio. Recorrer la tabla paso a paso en voz alta. Insistir en el valor inicial: sin él, acc empieza con el primer elemento. Ejemplo extra para la pizarra: contar votos → votos.reduce((acc, v) => { acc[v] = (acc[v] || 0) + 1; return acc; }, {}).
Más métodos útiles

some, every, includes… y encadenar

  • some — ¿al menos uno cumple? → true / false
  • every — ¿todos cumplen?
  • includes — ¿existe ese valor?
  • sort — ordena modificando el original
  • toSorted, slice — devuelven una copia
Encadenando métodosconst aprobados = alumnos
  .filter(a => a.nota >= 51)
  .map(a => a.nombre)
  .toSorted();
// ["Ana", "Sara"]

[1, 2, 3].some(n => n > 2);   // true
[1, 2, 3].every(n => n > 0);  // true
["a", "b"].includes("b");     // true
Como filter y map devuelven arrays, podemos encadenarlos: cada método trabaja sobre el resultado del anterior. Advertir sobre sort: modifica el array original y, con números, hay que pasar una función: nums.sort((a, b) => a - b).
Arrays anidados · ES2019

flat y flatMap

flat — aplanaconst anidado = [1, [2, 3], [4, [5, 6]]];

anidado.flat();
// [1, 2, 3, 4, [5, 6]]   (1 nivel)

anidado.flat(2);
// [1, 2, 3, 4, 5, 6]

anidado.flat(Infinity); // todos los niveles
flatMap — map + flat(1)const frases = ["hola mundo", "buen día"];

frases.map(f => f.split(" "));
// [["hola", "mundo"], ["buen", "día"]]

frases.flatMap(f => f.split(" "));
// ["hola", "mundo", "buen", "día"]

Caso real: cursos.flatMap(c => c.alumnos) → todos los alumnos en una sola lista.

flat recibe la profundidad (por defecto 1); con Infinity aplana todo. flatMap equivale a .map(...).flat() pero en un solo paso, y solo aplana un nivel. split(" ") convierte un string en un array cortando por espacios. Ambos devuelven un array nuevo; el original no cambia.
Métodos de Object

Recorrer un objeto

keys · values · entriesconst persona = {
  nombre: "Ana",
  edad: 25,
  ciudad: "La Paz",
};

Object.keys(persona);
// ["nombre", "edad", "ciudad"]
Object.values(persona);
// ["Ana", 25, "La Paz"]
Object.entries(persona);
// [["nombre", "Ana"], ["edad", 25], ...]
Recorriendofor (const clave in persona) {
  console.log(clave, persona[clave]);
}

Object.entries(persona)
  .forEach(([k, v]) => {
    console.log(`${k}: ${v}`);
  });

Los objetos no tienen map ni filter: los convertimos en array con estos métodos.

Object.keys/values/entries convierten un objeto en array, y así podemos usar todo lo visto antes. Mencionar Object.fromEntries como la operación inversa (array de pares → objeto). for...in recorre las claves.

Proteger y copiar objetos

freeze es superficial: los objetos anidados sí se pueden modificar.

Ejemplosconst config = Object.freeze({ tema: "oscuro" });
config.tema = "claro";       // ignorado
console.log(config.tema);    // "oscuro"

const user = Object.seal({ nombre: "Luis" });
user.nombre = "Leo";         // ✔ permitido
delete user.nombre;          // ✘ ignorado

const copia = Object.assign({}, user, { edad: 20 });
const copia2 = { ...user, edad: 20 }; // igual
const impide reasignar la variable, pero NO impide cambiar el contenido del objeto: para eso existe Object.freeze. Object.assign y el spread (...) crean copias superficiales. Útil para configuraciones y estados que no deben cambiar. En la siguiente diapositiva vemos por qué "superficial" importa.
Métodos de Object · copia profunda

JSON.stringify y structuredClone

El problema: copia superficialconst alumno = {
  nombre: "Ana",
  notas: [80, 90],
};

const copia = { ...alumno };
copia.notas.push(100);

console.log(alumno.notas);
// [80, 90, 100]  ¡el original cambió!
La solución: copia profunda// 1. JSON: objeto → texto → objeto
const texto = JSON.stringify(alumno);
// '{"nombre":"Ana","notas":[80,90]}'
const copia1 = JSON.parse(texto);

// 2. structuredClone (moderno)
const copia2 = structuredClone(alumno);
copia2.notas.push(100);
console.log(alumno.notas);
// [80, 90]  ✔ original intacto
JSON → como copia pierde funciones y undefined; las fechas pasan a texto structuredClone → copia profunda real: conserva Date, Map, Set; no copia funciones
Spread y Object.assign solo copian el primer nivel: los arrays y objetos anidados siguen siendo la misma referencia. JSON.stringify convierte un objeto en texto (lo usaremos para enviar datos con fetch en la clase 3) y JSON.parse hace lo contrario; combinados eran el truco clásico para copiar en profundidad. structuredClone (2022, disponible en todos los navegadores modernos y en Node 17+) es la forma recomendada hoy. Si el objeto tiene funciones, structuredClone lanza un error (DataCloneError).
Introducción a funciones

¿Qué es una función?

Un bloque de código con nombre que recibe datos, hace algo y devuelve un resultado. Se escribe una vez y se reutiliza.

Declaraciónfunction sumar(a, b) {
  return a + b;
}
Expresiónconst sumar = function (a, b) {
  return a + b;
};
Arrow function (ES6)const sumar = (a, b) =>
  a + b;

Se ejecuta llamándola con paréntesis: sumar(2, 3) → 5

Ya venimos usando funciones sin notarlo: las flechas que pasamos a map y filter son funciones. Tres formas de escribirlas; las tres hacen lo mismo. Diferencia práctica: las declaraciones se pueden llamar antes de definirse (hoisting).
