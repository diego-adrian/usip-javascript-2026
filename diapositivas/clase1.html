01 /

El nacimiento
1995

(1:30) Transición. Pregunta al grupo: ¿alguien sabe cuánto tiempo tomó crear la primera versión de JavaScript?
Contexto

La web de 1995 era estática

  • Páginas de solo HTML: texto, enlaces e imágenes
  • Cualquier validación de formulario requería un viaje al servidor
  • Netscape Navigator dominaba con casi el 80% del mercado
  • Netscape quería un lenguaje de scripting sencillo, para diseñadores y aficionados
EL PLAN DE NETSCAPE

Dos lenguajes, dos públicos

Java (de Sun Microsystems) para los componentes "serios" — los applets.

Un lenguaje ligero, embebido en el HTML, para "pegar" piezas e interactuar con la página.

(1:30 – 3:00) Imaginar llenar un formulario, enviarlo, esperar varios segundos con un módem de 28.8 kbps y recibir "campo email inválido". Ese era el problema. Netscape quería algo que corriera en el navegador del usuario.
Mayo de 1995
10

días

Lo que tardó Brendan Eich en escribir el primer prototipo.

Brendan Eich

  • Contratado por Netscape en abril de 1995
  • Inspiración: Scheme (funciones de primera clase), Self (prototipos) y Java (sintaxis)
  • Más tarde cofundó Mozilla y creó el navegador Brave
(3:00 – 4:15) Eich quería hacer "Scheme en el navegador", pero la dirección pidió que "se pareciera a Java". El resultado mezcla las tres influencias. Las prisas explican algunas rarezas que todavía arrastramos (typeof null === "object").
Un nombre, tres intentos

Mocha → LiveScript → JavaScript

MAYO 1995

Mocha

Nombre interno elegido por Marc Andreessen, cofundador de Netscape.

SEPTIEMBRE 1995

LiveScript

Así se lanzó en la beta de Netscape Navigator 2.0.

DICIEMBRE 1995

JavaScript

Renombrado tras la alianza con Sun. Una decisión de marketing para aprovechar la fama de Java.

Dato: la marca "JavaScript" hoy pertenece a Oracle, que la heredó al comprar Sun en 2010.

(4:15 – 5:15) El nombre "JavaScript" fue puro marketing: Java estaba de moda. Por eso el estándar oficial se llama ECMAScript — nadie podía usar libremente la marca.
Aclaración importante

Java ≠ JavaScript

JavaJavaScript
Creado porSun Microsystems (James Gosling)Netscape (Brendan Eich)
TipadoEstáticoDinámico
EjecuciónCompilado a bytecode (JVM)Interpretado / compilado JIT por el motor
ObjetosBasado en clasesBasado en prototipos
Uso originalAplicaciones y appletsScripts dentro de páginas web

"Java es a JavaScript lo que car es a carpet" — se parecen solo en el nombre.

(5:15 – 6:00) La confusión más común de los principiantes. Insistir: comparten parte de la sintaxis (llaves, if, for) por decisión de diseño, pero son lenguajes completamente diferentes.
02 /

Guerra de navegadores
y estandarización

(6:00) Transición.
1996 · Microsoft entra en escena

JScript y el caos de la compatibilidad

  • Microsoft aplicó ingeniería inversa y lanzó JScript en Internet Explorer 3 (agosto de 1996)
  • Dos implementaciones con comportamientos distintos
  • Nacen los letreros "Mejor visto en Netscape" o "…en Internet Explorer"
El código de la épocaif (document.all) {
  // Internet Explorer
  el = document.all["menu"];
} else if (document.layers) {
  // Netscape
  el = document.layers["menu"];
}
(6:00 – 7:15) Mostrar el código: los desarrolladores tenían que escribir todo dos veces. Esto motivó a Netscape a buscar un estándar neutral.
ECMA-262

Nace ECMAScript

En noviembre de 1996 Netscape lleva el lenguaje a Ecma International. El comité TC39 define el estándar ECMA-262.

1997

ES1

Primera edición del estándar.

1998

ES2

Ajustes editoriales para alinearse con ISO.

1999

ES3

Expresiones regulares, try/catch, mejor manejo de strings. La base durante 10 años.

JavaScript es la implementación más conocida; ECMAScript es la especificación.

(7:15 – 8:30) Distinción clave: ECMAScript = el estándar (la receta); JavaScript = una implementación (el plato). Por eso hablamos de "ES5", "ES6", "ES2024".
2000 – 2009

Una década de estancamiento

2000 – 2008

ES4: el estándar que nunca llegó

Propuesta muy ambiciosa: clases, tipos estáticos, módulos… El comité no logró acuerdo y fue abandonada en 2008.

DICIEMBRE 2009

ES5: el acuerdo

"use strict", JSON nativo, forEach, map, filter, reduce, getters y setters.

Mientras tanto, IE6 (2001) dominaba la web y casi no se actualizaba.

(8:30 – 9:30) Diez años sin cambios relevantes en el lenguaje. Pero, aunque el lenguaje no avanzaba, la forma de usarlo sí cambió radicalmente, como veremos ahora.
03 /

La web se vuelve
aplicación

(9:30) Transición.
2004 – 2006

Ajax y jQuery

Ajax (2005)

  • Término acuñado por Jesse James Garrett
  • Usa XMLHttpRequest para pedir datos sin recargar la página
  • Gmail (2004) y Google Maps (2005) demuestran el potencial

jQuery (2006)

  • Creado por John Resig: "write less, do more"
  • Ocultaba las diferencias entre navegadores
jQuery$("#boton").click(function () {
  $(".menu").fadeIn();

  $.get("/api/datos", function (res) {
    $("#lista").html(res);
  });
});
(9:30 – 11:00) Ajax cambió la percepción de JS: dejó de ser "un juguete para efectos" y pasó a construir aplicaciones reales. jQuery llegó a usarse en la mayoría de los sitios web más visitados.
2008 – 2010

Velocidad y salto al servidor

SEPTIEMBRE 2008

Google Chrome + motor V8

Compilación JIT a código máquina. JavaScript pasa a ser muchas veces más rápido y desata una carrera de rendimiento entre navegadores.

2009 · 2010

Node.js + npm

Ryan Dahl toma V8 y lo saca del navegador. Con npm nace el mayor registro de paquetes del mundo.

Un servidor web con Node.jsconst http = require("http");

http.createServer((req, res) => {
  res.end("Hola desde el servidor");
}).listen(3000);
(11:00 – 12:30) Momento clave: por primera vez, un mismo lenguaje sirve para frontend y backend. Node usa un modelo asíncrono y no bloqueante, ideal para muchas conexiones simultáneas.

Junio 2015 · ES6 / ES2015

La gran renovación

Antes (ES5)var nombre = "Ana";
var saludar = function (n) {
  return "Hola, " + n + "!";
};
function Persona(n) { this.n = n; }
Después (ES2015)const nombre = "Ana";
const saludar = (n) => `Hola, ${n}!`;

class Persona {
  constructor(n) { this.n = n; }
}
let / constarrow functionsclass template literalsimport / exportPromise destructuringspread / restMap / Set
(12:30 – 14:00) La actualización más grande de la historia del lenguaje. Mucho de lo que vamos a aprender en el curso viene de aquí. Comparar ambos bloques en voz alta.
